CUSTOMER SHOPPING & SALES ANALYSIS

PROJECT OVERVIEW
This project analyzes customer shopping behavior and sales data using Python and Power BI.

TOOLS USED
- Python
- Pandas
- NumPy
- Matplotlib
- Google Collab
- Power BI
- Microsoft Excel/CSV

PYTHON ANALYSIS
- Data cleaning and preprocessing
- Exploratory Data Analysis (EDA)
- Analysis of customer demographics
- Analysis of purchase behavior
- Analysis of spending patterns
- Data visualization

POWER BI DASHBOARD
The interactive dashboard presents:
- Total Customers
- Total Revenue
- Average Purchase Amount
- Average Review Rating
- Revenue by Category
- Customers by Age Group and Spending Segment
- Customers by Location
- Payment Method
- Gender
- Item Purchased
- Discount Applied
- Subscription Status
- Season
- Frequency of Purchases
- Previous Purchases

PROJECT OBJECTIVE
The objective of this project is to understand customer purchasing patterns, sales performance, and customer behavior through data analysis and visualization.

CONCLUSION
The project demonstrates how data analysis and visualization tools can be used to convert raw customer shopping data into meaningful business insights.
